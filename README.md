本プログラムでは、単純な1回勝負のじゃんけんではなく、
3回勝負形式にすることで勝利数を集計し、
最終的な勝者を判定できるようにしました。
制作にあたっては、学習した
変数、条件分岐（if文）、繰り返し処理（for文）、
ランダム処理（Random）を単独で使うだけではなく、
一つのプログラムとして組み合わせて
実装することを意識てつくりました。
自分でコードを書き、エラーの原因を調べながら修正し、
最終的にGitおよびGitHubを利用して公開まで行いました

学習した内容

・変数（int、String）
・ユーザー入力（Scanner）
・ランダム処理（Random）
・条件分岐（if / else if / else）
・繰り返し処理（for文）
・論理演算子（&&、||）
・じゃんけんの勝敗判定処理
・Git / GitHubを利用したソースコード管理
